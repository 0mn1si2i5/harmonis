# Harmonis 使用指南

## 第一次配音

1. 「服务设置」保存 MiniMax **中国站** API Key，不需要把密钥发到聊天。账户需具备克隆权限并完成平台要求的认证。
2. 「我的音色 → 建立音色」允许麦克风，按参考稿自然读 30–60 秒；可暂停、重录、试听，也可上传 MP3/M4A/WAV。
3. 点「使用这段录音」会在本机转换和检查；点「提交 MiniMax 克隆」才上传给 MiniMax。录音须 10–300 秒，规范化后不超过 20 MB。可选参考录音须短于 8 秒并填写对应文字。
4. 克隆成功后选「使用这个音色」，输入文案，选择语速与情绪，点「生成配音」。新建音色需在 7 天内正式使用一次，费用及有效期以供应商账户为准。
5. 每次生成留一版。在版本列表里试听、比较，点「选定」标出要用的那一版；播放旧结果不发起生成请求。

默认整篇生成。分段模式下每段可以单独改语速、情绪等参数，改过的参数标黄，可以恢复成项目设置；读音词典整个项目共用。「生成本段」「生成未选定或稿已改的 N 段」「生成全部」依次处理，失败时保留已成功的结果。

## 克隆稿与成品导出

「导入克隆稿」读一个文件夹里的 .txt：一个文件一段，段名用文件名；文件名下划线前相同的分成一个项目（例如 B站\_01.txt、B站\_02.txt 成为「B站」项目）。同一文件夹里的「读音词典.txt」按 MiniMax 读音规则写进项目，一行一条，`#` 开头是注释：

```
长到/(zhang3)到
一维/(yi1)(wei2)
```

稿件改了以后点「重新读取稿件」：按段名更新文字，新文件加在后面，已生成的版本都保留。选定那版念的文字和现在的稿不一样时，段落标成「稿已改」。

段落栏显示每段字数、按每秒 4 字估的时长和状态（未生成、几版、已选定、稿已改）。「导出选定版本」按段落顺序导出每段选定的那一版，文件名用段名；可以打包 ZIP 或合并成一条，WAV 或 MP3，可选：

- 响度统一到 -16 LUFS，峰值不超过 -1 dBTP（ffmpeg loudnorm 两遍）
- 去掉首尾静音，各留 0.1 秒
- 采样率 48 kHz
- 附带 SRT 字幕，时间来自 MiniMax 返回的句子时间，按去掉的静音平移

合并为顺序拼接，不是配音与音乐混音。导出文件下载一次后删除。版本和项目都可以删除，音频文件一起删掉。

建立音色时，录音会显示输入电平；用上的录音在本机测出时长、峰值、平均响度和底噪，超出建议范围的标黄。

「查看实际请求」显示当前配置对应的供应商参数。语速范围 0.5–2.0、音量 0.01–10、音调整数 -12–12；情绪选项随模型变化，自动情绪省略该字段。支持停顿标记、读音词典和文本规范化。当前提供 speech-2.8 与 speech-2.6 的 HD/Turbo。

## 音乐

保存具备 Music 访问权限的 ElevenLabs API Key 后使用音乐页面。描述模式对应 prompt、music_length_ms、force_instrumental；结构模式对应 v2/v2.5 的 composition_plan.chunks，二者不会混用。提供 music_v1 / v2 / v2_5。

输出可选 MP3 44.1 kHz/128 kbps 或 48 kHz/192 kbps；下载 WAV 在本机转换，保留声道，但不提升原始音质。暂不提供原始 PCM：在真实响应声道约定确认前避免错误封装。高码率需账户具备相应权限。

页面按公开 API 标价 $0.15/分钟估算用量价值，套餐、抵扣、最低计量、税费及商用许可以账户实际规则为准。每次重做是新的生成调用。

## 编曲（本机合成）

「编曲」页调用 `synth/` 里的 Python 引擎，不用 API Key，不计费。选一个曲谱（`synth/scores/*.py`），可以改小节数、打开无缝循环、换随机种子，「5/6/9 小节循环」一键设好抖音要的长度。循环模式去掉弱起，把混响和延迟的尾音折回开头，文件长度正好是整数小节。

拨弦数据每行一步：`小节,拍,牌数`。牌数决定音高：以第一步的牌数为起点 D4，多一张升一级 C 大调五声音阶，少一张降一级，超过上限按八度折回。版本列表的波形上画了小节线。

Harmonis启动时按顺序找第一个能 `import numpy, scipy` 的 Python：环境变量 `HARMONIS_PYTHON`（兼容 `SHENGJIAN_PYTHON`）、PATH 里的 `python3`、`/opt/anaconda3/bin/python3`、`/opt/homebrew/bin/python3`、`/usr/local/bin/python3`、`/usr/bin/python3`。顶栏的 Python 状态显示找到的解释器。

新曲谱放进 `synth/scores/`：导出 `SONG = dict(bpm=..., bars=...)` 和 `arrange(song, plucks)`，模块文档字符串第一行是页面上显示的名字。命令行用法和引擎结构见 [synth/README.md](synth/README.md)。

## 删除与清理

- **我的音色 → 删除**：默认仅从Harmonis移除，也可明确选择同时调用 [MiniMax 删除音色接口](https://platform.minimax.cn/docs/api-reference/voice-management-delete)。云端失败时保留本机记录。删除会清空项目与段落中的音色选择，保留已有配音和原始录音。
- **我的音色 → 录音管理**：试听和删除本机保存的克隆录音、参考音频；不连带删除音色或作品。克隆进行中不能删除录音。
- **任务记录 → 清理已结束记录**：仅清理成功、失败和中断记录，不删除作品，也不清理进行中的任务。
- **服务设置 → 移除密钥**：只移除本机配置，不注销账户、不撤销供应商的 Key。该服务正在运行任务时不可移除。
- 项目和生成版本已有删除入口；删除项目会连同其版本及音频文件一起删除。每种删除操作都会先说明范围并要求确认。
